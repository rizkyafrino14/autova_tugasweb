# Autova Web

Autova Web is a PHP and Bootstrap-based web application providing integrated solutions for vehicle financing and insurance services. 

> **Note:** This repository was created to fulfill an assignment for the Web Development course under the guidance of **Mr. Imam Muthohar**.

---

## 🛠️ Built With

* [PHP](https://www.php.net/) - Server-side scripting language
* [Bootstrap](https://getbootstrap.com/) - Frontend CSS framework

## 💻 Getting Started

To run this project locally using XAMPP/Laragon:

1. Clone or download this repository.
2. Place the project folder inside your web server directory (e.g., `htdocs` for XAMPP or `www` for Laragon).
3. Start the Apache server in your local dashboard.
4. Open your browser and navigate to `http://localhost/autova_tugasweb`.
